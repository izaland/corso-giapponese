# Corso di giapponese per principianti

Sito di supporto per il corso di giapponese per italiani principianti.

## Struttura

- `index.html`: home per gli studenti
- `lezioni/`: pagine delle singole lezioni
- `pratica/`: mini app di pratica con quiz e tracing
- `materiali/`: guide e tabelle di consultazione
- `js/`: script JavaScript riutilizzabili
- `img/`: immagini del sito

## Lezione 1

- Saluti e presentazione
- Hiragana: serie a, ka e sa
- Quiz e tracing
- Pillola culturale: ojigi

## Aggiornare il sito

Dopo ogni lezione, aggiungi una nuova pagina in `lezioni/` e aggiorna l’indice in `index.html`.

## JavaScript e immagini

- Inserisci i file JavaScript in `js/`, per esempio `js/quiz.js`.
- Inserisci le immagini in `img/`, per esempio `img/lezione-01.png`.
- Richiama uno script con `<script src="js/quiz.js"></script>`.
- Inserisci un’immagine con `<img src="img/lezione-01.png" alt="Descrizione dell’immagine">`.

## GitHub Pages

Attiva GitHub Pages da **Settings → Pages**, scegliendo il branch `main` e la cartella `/ (root)`.
